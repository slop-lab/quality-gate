# QG File Rules

`@slop-lab/qg-rules-files` provides QG checks for required files, file size and
line limits, directory file limits, document references, and Markdown policies.
Requires Node.js 24 or later. Licensed under MIT.

These rules are included by `@slop-lab/qg-rules-recommended` and the `qg` CLI.

See [file policies](https://github.com/slop-lab/quality-gate/blob/main/docs/file-policies.md),
[file limits](https://github.com/slop-lab/quality-gate/blob/main/docs/generated-artifacts.md),
and [directory limits](https://github.com/slop-lab/quality-gate/blob/main/docs/directory-limits.md).
